## Referensi desain yang ditinjau

Keempat repository dipelajari sebagai referensi; bukan dependency runtime dan tidak dipasang sebagai skill global.

- [Awesome Design Skills](https://github.com/bergside/awesome-design-skills): registry gaya ditinjau untuk memilih satu bahasa visual yang konsisten, bukan mencampur gaya setiap workspace.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): hierarki, progressive disclosure, label/focus, kontrol yang konsisten, responsive bounds dan reduced motion. Skala kontrol disesuaikan untuk editor desktop yang padat.
- [Oil UI](https://github.com/oil-oil/oil-ui): konten/preview menjadi fokus, refinement berdasarkan screenshot dan mengurangi panel yang tidak membantu pekerjaan.
- [AI Design Skills](https://github.com/Owl-Listener/ai-design-skills): cakupannya terutama interaksi produk AI. Tidak ditambahkan orkestrasi agent atau dependency AI pada editor offline.

## Batas yang tidak boleh disebut selesai penuh

- **Peta GTA lengkap yang streaming**, arsip RPF terenkripsi/nested, serta Enhanced tidak diselesaikan oleh importer studio. Resource YMAP/YTYP/YDR/YTD yang didukung dan OPEN RPF tetap memerlukan dependency aset lokal yang lengkap.
- **Redistribusi seluruh source/renderer CodeWalker** belum memiliki izin yang terselesaikan; pekerjaan ini tidak membundelnya.
- **Sertifikasi hasil di GTA/FiveM untuk semua ped/kendaraan pengguna** tidak digantikan oleh fixture, parser, preview GPU atau round trip Blender.
- Engine kreatif pihak ketiga tetap memakai UI bawaannya. Pembenahan menyatukan shell dan alat native DITASHA, bukan menulis ulang semua aplikasi pihak ketiga.

Lihat `PHOTO_BOOTH.md`, `PHOTO_BOOTH_CINEMATIC.md`, `NATIVE_BUILD.md`, `INSTALLER_AND_WORKSPACE.md` dan `YMT_CREATOR.md` untuk workflow dan batas teknis masing-masing.
