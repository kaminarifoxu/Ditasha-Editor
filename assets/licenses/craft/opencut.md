This edition uses the original editor, timeline, media storage and renderer with a DITASHA local project launcher and routing adapter. It does not include the new OpenCut rewrite. Service-backed panels, AI transcription, remote font loading, feedback and online changelogs are excluded. Available asset tabs: imported media, text, effects and settings. Use local audio files in Media. System fonts are used; projects requesting uninstalled fonts may render differently.

Dependency license notices are provided in THIRD-PARTY-NOTICES.txt. Media codecs and GPU effects depend on the hardware and Electron runtime. Project storage is local to DITASHA; deleting application data removes locally stored projects and media. Export finished videos before clearing data.
