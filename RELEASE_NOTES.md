DITASHA Editor 1.4.0

- New Converter workspace: batch PNG/JPG/WebP/DDS to a new Legacy YTD, YTD textures to PNG/JPG/WebP/DDS, and image format conversion. Save individually or export a ZIP.
- Static model export to GLB from YDD/YDR/YFT Legacy, OBJ and STL. Meshes and UVs are retained; GTA materials, skinning, skeletons and animations are not exported.
- Expanded 3D viewer: Perbesar 3D opens the existing model in a larger view with camera, wireframe and snapshot controls. Escape returns to the previous layout.
- Clothing pack maker: import files or a resource folder, group clothing by ped and component, filter/search, preview YDD models, inspect filename findings, and build a FiveM resource ZIP with fxmanifest.lua, stream assets and build notes.
- Supports replacement clothing and existing add-on collections with imported YMT + shop .meta. Collection names and metadata are preserved. Generating new YMT collections, slot reservations, DCT/grzy project import and Enhanced resources are not available in this release.
- DDS DXT1/DXT3/DXT5 and RGBA/BGRA 32-bit can now be opened in the editor. YTD/DDS exports are uncompressed and contain one mipmap.
- Canceled saves preserve the pack's unsaved state. Existing portable updater behavior is retained and tested in Windows CI.
