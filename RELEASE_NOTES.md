DITASHA Editor 1.3.2

- Helper update dijalankan dari folder tetap di luar ekstraksi portable, dengan konfirmasi bahwa PowerShell sudah berjalan sebelum editor ditutup.
- Penantian proses toleran terhadap aplikasi yang keluar di antara pemeriksaan; EXE lama dicadangkan dan dipulihkan jika pemasangan gagal.
- Laporan kegagalan pemasangan ditampilkan ketika aplikasi dibuka kembali.
- Dialog update minimalis dengan tahapan unduh/verifikasi/pasang dan ukuran unduhan. Konfirmasi pemasangan mengikuti tema DITASHA.
- Pengujian helper penggantian EXE dan kegagalan staging dijalankan di Windows melalui GitHub Actions.

Untuk berpindah dari v1.2.2 yang updater-nya bermasalah: unduh DITASHA-Editor.exe dari rilis ini, tutup aplikasi lama, lalu ganti EXE lama secara manual sekali. Pembaruan updater berlaku setelah EXE baru dijalankan.
